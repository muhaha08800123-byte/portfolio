## 🎨 จุดเด่นของเว็บไซต์ (Features)
- **Multi-page Structure**: แบ่งหน้าเว็บเพจแยกจากกันอย่างชัดเจนตามแต่ละเมนู
  - `index.html` : หน้าแรก (Home) แนะนำตัวเองและแสดงภาพรวม
  - `education.html` : หน้าข้อมูลการศึกษาทุกระดับในรูปแบบ Interactive Timeline
  - `portfolio.html` : หน้ารวมผลงาน พร้อมระบบ Filter Tabs (งานวาด, กิจกรรมมหาลัย, งานโมเดล 3D) และ Lightbox ซูมดูภาพ
  - `activity.html` : หน้าบันทึกกิจกรรมและโครงการอบรมเชิงปฏิบัติการ
  - `contact.html` : หน้าข้อมูลการติดต่อครบถ้วน พร้อมระบบคลิกคัดลอกอีเมล และฟอร์มส่งข้อความ
- **Dark / Light Mode**: สลับโหมดสว่างและโหมดมืดได้ พร้อมจดจำการตั้งค่าข้ามหน้าผ่าน `localStorage`
- **Color Palette**: ออกแบบด้วยชุดสีตามที่กำหนด `#E0F7FA`, `#2962FF`, `#00B8D4`, `#303F9F`
- **Responsive Web Design**: รองรับการแสดงผลทุกขนาดหน้าจอ ทั้งสมาร์ทโฟน แท็บเล็ต และคอมพิวเตอร์
