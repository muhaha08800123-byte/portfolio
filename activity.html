TRAINING & EXPERIENCES

กิจกรรมและการอบรม

ประสบการณ์การเข้าร่วมกิจกรรม พัฒนาศักยภาพเชิงลึกผ่านการอบรมเชิงปฏิบัติการ และการทำงานร่วมกับองค์กรและเครือข่าย

WORKSHOP // การอบรมเชิงปฏิบัติการ

อบรมเชิงปฏิบัติการเทคโนโลยีสื่อดิจิทัลและอินเตอร์แอคทีฟ

เข้าร่วมการอบรมเข้มข้นเกี่ยวกับการสร้างสรรค์เนื้อหาสื่อสมัยใหม่ การใช้เครื่องมือดิจิทัลสำหรับการสื่อสาร และการผสมผสานเทคโนโลยีอินเตอร์แอคทีฟในงานสื่อนฤมิต จัดโดยคณะวิทยาการสารสนเทศ

มหาวิทยาลัยมหาสารคาม Certificate
EVENT CREW // ทีมปฏิบัติการสื่อ

ทีมผลิตสื่อโสตทัศนูปกรณ์และกิจกรรมมหาวิทยาลัย

ปฏิบัติหน้าที่ฝ่ายเทคนิคมีเดีย บันทึกภาพกิจกรรม และควบคุมการแสดงผลสื่อภาพและเสียงในกิจกรรมสำคัญของมหาวิทยาลัยมหาสารคาม

คณะวิทยาการสารสนเทศ Media Staff
CAMP // ค่ายพัฒนาศักยภาพ

ค่ายสานสัมพันธ์และแลกเปลี่ยนความรู้สื่อนฤมิต (New Media Camp)

เข้าร่วมกิจกรรมค่ายพัฒนาทักษะการทำงานเป็นทีม การระดมสมองเพื่อแก้โจทย์ด้านการออกแบบสื่อสร้างสรรค์ และการนำเสนอผลงานมินิโปรเจกต์ร่วมกับเพื่อนร่วมรุ่น

สื่อนฤมิต มมส. Teamwork
SEMINAR // สัมมนาวิชาการ

สัมมนาเจาะลึกทิศทางนวัตกรรมสื่อเสมือนและ 3D Virtual Worlds

เข้าร่วมฟังบรรยายพิเศษจากวิทยากรผู้เชี่ยวชาญในอุตสาหกรรมสร้างสรรค์ อัปเดตแนวโน้มเทคโนโลยี 3D Modeling, Game Engine, Virtual Production และอนาคตของอาชีพสื่อนฤมิต
